# 目的
この世界の現在の状況を反映した、架空ニュースを1件生成する。

# 出力形式
以下の形式で出力してください（JSON）:
{
  "title": "記事タイトル",
  "digest": "三行程度の要約文（導入）",
  "author": "記者名または匿名",
  "location": "出来事が起きた地名",
  "content": "300文字程度の記事本文",
  "faction": "関係する国家や勢力",
  "category": "政治 / 軍事 / 経済 / 事件 / 災害 など"
}

# 制約
- 一度に1記事のみ出力してください。
- すでに起きた出来事の続報や、今後の波及に関する仮説を含めても構いません。
- 読者にとって関心が高そうな話題（戦争の兆候、同盟、災害、新発見など）を優先的に扱ってください。
- 世界地図（マップ）上の「name」「type」「owner」を参照して、適切な場所や国家名を用いてください。
- 架空であることを前提にしており、現実世界とは関係ありません。

# 文章スタイル
- 客観的でありながら、やや物語性を帯びた「新聞記事」風。
- 読者がその地域の情勢を把握しやすくなるよう配慮してください。
- digestに含まれる三行の要約は、それぞれ20文字以上30文字以下とする(三行合計で60~90文字。改行コードは字数に含まない)

# ニュースカテゴリの出現確率指示
次のニュースカテゴリの中から、ランダムにひとつ選び、その内容に沿ったニュースをひとつ生成してください。
以下のカテゴリはおおよその出現確率の目安です。確率は強制ではなく、偏りを演出するための参考としてください。

## ニュースカテゴリと確率
- 戦争・軍事（20%）: 戦争の勃発、前線の移動、征服、停戦など
- 技術・魔法開発（15%）: 新兵器の開発、魔法の研究成果、新素材の発見など
- 政治・外交（15%）: 同盟締結、条約違反、内政の変化、王政の交代など
- 経済・貿易（10%）: 交易協定、物流拠点の開発、商業都市の拡大など
- 宗教・神秘（10%）: 精霊信仰、聖地の発見、古代遺跡の調査など
- 恋愛・人間ドラマ（10%）: 異種族間の結婚、貴族同士の政略結婚、失恋事件など
- 自然災害・事故（5%）: 火山噴火、地震、疫病の流行など
- 文化・祝い事（10%）: 祭典、即位式、建国記念、芸術的成果など
- その他（5%）: 特殊事件、未分類の出来事など

# 制約
- 選ばれたカテゴリに従って、世界観に合った自然なニュースを構築すること。
- ニュースはあくまで「この世界で実際に報道されたような文体」で記述すること。
- 誇張・偏見・視点の偏りをあえて含めてもよい。
